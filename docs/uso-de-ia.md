# Declaración de uso de herramientas de IA

Como lo permite el enunciado del proyecto, el equipo usó herramientas de inteligencia artificial como apoyo. Aquí se declara en qué se usaron.

| Fecha | Herramienta | Para qué se usó | Qué revisó o cambió el equipo |
|---|---|---|---|
| 12/11/2026 | Claude (Anthropic) | Apoyo para redactar la visión del producto, el backlog inicial, la Definition of Done y el README de la Semana 0, y para preparar la estructura del repositorio. | El equipo eligió el dominio (cuestionarios), los roles y el alcance, y revisó y ajustó los documentos. |

## Compromiso del equipo

- Todo el código y las decisiones del proyecto las podemos explicar sin ayuda de la IA.
- Lo que genere la IA se revisa antes de subirlo al repositorio y se prueba igual que el resto del código.
- Esta tabla se actualiza en cada sprint en que se use una herramienta de IA.
